# Система управління студентами

## Опис
Програмна система призначена для автоматизації роботи з інформацією
про студентів, викладачів, навчальні групи, предмети та оцінки.

## Функціональність
- створення та редагування даних студентів;
- робота з викладачами та адміністраторами;
- створення навчальних груп;
- додавання та видалення студентів із груп;
- збереження інформації про предмети;
- додавання та редагування оцінок;
- пошук студентів за ПІБ, логіном або номером студентського квитка;
- виведення оцінок студентів;
- надсилання повідомлень за допомогою патерна Observer;
- використання патерна Singleton для менеджера системи;
- виконання модульних тестів.

## Запуск
bash
python main.py

## Запуск модульних тестів
python -m unittest discover -s tests -p "test_*.py"

## Перевірка покриття коду
coverage run -m unittest discover -s tests -p "test_*.py"
coverage report
coverage html
